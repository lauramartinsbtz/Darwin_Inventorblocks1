INVENTORBLOCKS v5.3 - MATEMÁTICA E VARIÁVEIS

Novidades:
- Nova categoria Matemática no menu lateral.
- Botão "Criar nova variável" abre o diálogo nativo do Blockly e pergunta o nome.
- Bloco "Atribuir [variável] = [inteiro]" para definir valores inteiros.
- As variáveis aparecem no código Arduino gerado como int, com nomes adaptados para identificadores C++ válidos.
- Durante a execução em tempo real no navegador, os valores das variáveis são armazenados localmente pelo InventorBlocks.
- Nenhuma alteração de firmware é necessária para esta etapa porque a atribuição de variáveis faz parte da lógica executada no navegador.
