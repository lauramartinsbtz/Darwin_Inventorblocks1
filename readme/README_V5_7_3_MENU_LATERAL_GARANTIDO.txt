INVENTORBLOCKS v5.7.3 - MENU LATERAL GARANTIDO

Esta versão corrige especificamente o desaparecimento do menu lateral.

Funcionamento:
1. O Blockly tenta criar sua toolbox nativa normalmente.
2. O programa mede se a toolbox realmente existe e está visível.
3. Se a toolbox nativa não estiver visível, um menu lateral próprio do
   InventorBlocks aparece automaticamente.
4. Nesse menu, clicar em um bloco adiciona o bloco ao workspace.

Categorias preservadas:
- Controle
- Entrada
- LED
- Sirene
- Matemática
- Sensores
- Servo

Blocos preservados:
- Início
- SE / Então
- Esperar
- Ler botão
- Ligar/desligar LED
- Ligar/desligar sirene
- Criar variável
- Atribuir
- Número inteiro
- Exibir
- HC-SR04
- LerLuz A-0/A-1
- Servo 9G / Ângulo

Mapeamento:
D0 = GPIO15
D1 = GPIO18
D2 = GPIO40
D3 = GPIO39
A-0 = GPIO1
A-1 = GPIO2
HC-SR04 TRIG = GPIO16
HC-SR04 ECHO = GPIO17
